# mi-primer-pr

Repositorio de práctica para aprender a hacer Pull Requests en GitHub.

## ¿Qué es un Pull Request?

Un Pull Request (PR) es una forma de proponer cambios en un proyecto. En lugar de modificar el código directamente, creas una copia, haces tus cambios ahí, y luego pides que los revisen antes de incorporarlos.

## Pasos para contribuir

1. Clona el repositorio en tu computador
2. Crea una rama nueva con `git checkout -b nombre-de-tu-rama`
3. Haz tus cambios
4. Confirma los cambios con `git commit -m "descripción del cambio"`
5. Sube la rama con `git push origin nombre-de-tu-rama`
6. Abre un Pull Request en GitHub
